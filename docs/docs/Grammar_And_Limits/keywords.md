# Keywords

| Group | Words |
| --- | --- |
| declaration | `fn` `struct` `class` `enum` `mark` `bind` `to` `extend` `type` `global` `extern` `import` `pub` `where` `macro` |
| binding | `let` `var` `mut` `weak` `uniq` |
| control | `if` `elif` `else` `while` `loop` `for` `in` `match` `return` `break` `continue` `defer` `async` `await` |
| value | `self` `Self` `super` `true` `false` `nil` |
| operator-like | `as` `into` `is` `operator` `dyn` `unsafe` `move` |
| contextual | `take` in a pattern, `some` and `typeof` in a type, `from` after a borrowed type — names everywhere else |
| sigil | `$` before a member name: the compiler's own |
